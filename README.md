# TurboTranscode releases

Signed release builds of **TurboTranscode** by Nighttrail Technologies LLC.

This repository holds release files only; the source code is private.
Installed copies of TurboTranscode check this repository's releases for
updates. Every installer is code-signed by Nighttrail Technologies LLC and
carries a separate update signature, and TurboTranscode installs an update
only when both check out.

Please don't download or install files from anywhere else.
